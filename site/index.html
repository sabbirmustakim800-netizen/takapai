১️⃣ Android অ্যাপ — শুধু “চোখ”

আপনার ফোনে ইনস্টল হয়। বিকাশ/রকেট/নগদ থেকে আসা SMS পড়ে সার্ভারে পাঠায়। আর কিছু নয় — কোনো হিসাব এখানে হয় না। এই কারণেই অ্যাপে “সার্ভার লোকেশন” দিতে হয় — কোথায় পাঠাবে সেটা অ্যাপকে জানাতে হবে।

২️⃣ সার্ভার — আসল “মস্তিষ্ক”

Node.js অ্যাপ। গ্রাহকের অর্ডার রাখে, SMS-এর সাথে মেলায় (টাকা + নম্বর + TrxID), আর এক-বার নিয়ম মানে। ডাটাবেস এখানেই থাকে।

৩️⃣ আপনার ওয়েবসাইট/অ্যাপ — “হাত”

অর্ডার তৈরি করে সার্ভারে পাঠায় (API), আর ম্যাচ হলে সার্ভার আপনার webhook-এ খবর দেয়। তখন আপনি পণ্য বা সার্ভিস ডেলিভারি দেন।

২

“Unknown sources” চালু করুন

Settings → Apps → (আপনার ব্রাউজার / ফাইল ম্যানেজার) → Install unknown apps → Allow। Android 7-এ: Settings → Security → Unknown sources।

৩

Play Protect বন্ধ করুন

Play Store → প্রোফাইল → Play Protect → ⚙️ Settings → Scan apps with Play Protect বন্ধ করুন। নাহলে “unsafe app blocked” দেখিয়ে ইনস্টল আটকে দেবে। ইনস্টল শেষ হলে Play Protect আবার চালু করে দিতে পারেন — অ্যাপ চলতে কোনো সমস্যা হবে না।

৪

ইনস্টল করে খুলুন

ফাইলটি ট্যাপ করে Install → Open।

৫

SMS অনুমতি দিন (বাধ্যতামূলক)

অ্যাপ খোলার সঙ্গে সঙ্গে পপ-আপ আসবে — Allow চাপুন। অনুমতি না দিলে অ্যাপে ঢোকাই যাবে না (গেট স্ক্রিন পুরোটা ঢেকে রাখবে)। পপ-আপ না এলে → “সেটিংসে গিয়ে অনুমতি দিন” → Permissions → SMS → Allow।

সার্ভারের ঠিকানা ও পেয়ারিং কোড দিন

অ্যাপে সার্ভার লোকেশন লিখুন (দেখুন সার্ভার লোকেশন)। তারপর ড্যাশবোর্ড → ডিভাইস → পেয়ারিং কোড তৈরি → ৮ অক্ষরের কোডটি অ্যাপে বসিয়ে ডিভাইস সংযুক্ত করুন। এই মুহূর্তে অ্যাপটি নিজের ইউনিক ডিভাইস কী পায়।

ফোনটি চালু রাখুন

Settings → Battery → Battery optimization → টাকাপাই → Don’t optimize। নাহলে ব্যাকগ্রাউন্ডে অ্যাপ বন্ধ হয়ে SMS আটকে যেতে পারে।

“সার্ভার লোকেশন” কী, কেন লাগে

অ্যাপটি শুধু SMS পড়ে। সেই SMS কোথায় পাঠাবে — সেটাই সার্ভারের ঠিকানা। আপনার নিজের সার্ভার আপনি নিজেই চালাবেন, তাই অ্যাপকে সেটি বলে দিতে হয়।

🏠 নিজের কম্পিউটারে (পরীক্ষার জন্য)

npm start চালানোর পর কম্পিউটারের লোকাল IP দিন — যেমন http://192.168.0.5:3000। ফোন ও কম্পিউটার একই WiFi-তে থাকতে হবে। শেষে / দেবেন না।

☁️ অনলাইনে (সবসময়ের জন্য)

সার্ভারটি Render / VPS-এ চালালে যে ঠিকানা পাবেন সেটাই দিন — যেমন https://takapai-api.onrender.com। HTTPS বাধ্যতামূলক, নাহলে ডিভাইস কী প্লেইনটেক্সটে যায়।

যে কম্পিউটারে এটি চলছে, সেটার ঠিকানাই অ্যাপে দিতে হবে। ড্যাশবোর্ড একই সার্ভারেই চলে — ব্রাউজারে http://192.168.0.5:3000 খুললেই পাবেন।

অবশ্যই মেনে চলুন

• সিগনেচার যাচাই করুন — নাহলে যে কেউ ভুয়া “পেমেন্ট হয়েছে” পাঠাতে পারবে।

• webhook ডুপ্লিকেট আসতে পারে — order.id দিয়ে একবারই ডেলিভারি দিন।

সেটিংকাজসুপারিশ
webhook URLম্যাচ হলে এই ঠিকানায় POST যাবেআপনার সাইটের /payment-hook
অর্ডারের মেয়াদকতক্ষণ টাকার অপেক্ষা করবে১৮০০ সেকেন্ড (৩০ মিনিট)
আগে-পরে সহনশীলতাগ্রাহক আগে টাকা দিয়ে পরে অর্ডার দিলে কত সেকেন্ড পেছনে দেখবে৩০০ সেকেন্ড
TrxID পুরো সিস্টেমে একবারই। একটি বাস্তব পেমেন্ট একবার যাচাই হলে আর কোনো অর্ডারে ব্যবহার করা যাবে না — এমনকি অন্য অ্যাকাউন্টেও নয়। এটাই স্ক্রিনশট জালিয়াতি বন্ধ করে।

ডাটাবেস কোথায় থাকে — ক্লাউড লাগে না

ডিফল্ট ডাটাবেস আপনার নিজের মেশিনেই (একটি SQLite ফাইল)। কোনো ক্লাউড অ্যাকাউন্ট, মাসিক বিল বা লক-ইন নেই। চাইলে নিজের ক্লাউড স্পেস যোগ করে ব্যাকআপ রাখতে পারেন।

কীকোথায় থাকেখরচ
ডিফল্ট ডাটাবেসdata/app.db — যে মেশিনে সার্ভার চলছেশূন্য
নিজের ক্লাউড ব্যাকআপCloudflare R2 / Amazon S3 / Backblaze B2 / MinIO — আপনার নিজের অ্যাকাউন্টসাধারণত ১০ GB ফ্রি
ব্যাকআপ এনক্রিপ্টেড। প্রতিটি ব্যাকআপ AES-256-GCM দিয়ে লক করা হয় — বাকেটের চাবি কারো হাতে চলে গেলেও পাসওয়ার্ড হ্যাশ বা webhook সিক্রেট পড়া যাবে না।

ব্যাকআপ চালু করবেন যেভাবে

  1. R2/S3/B2-এ একটি বাকেট বানিয়ে Access Key ID ও Secret Key নিন।
  2. ড্যাশবোর্ড → ব্যাকআপ ট্যাবে Endpoint, Bucket, Access Key বসান।
  3. সংযোগ পরীক্ষা চাপুন — সব ঠিক থাকলে “সংযোগ ঠিক আছে ✓” দেখাবে।
  4. সংরক্ষণ করুন। এরপর এখনই ব্যাকআপ চাপলেই প্রথম কপি যাবে।
  5. স্বয়ংক্রিয় ব্যাকআপ (মিনিট) — যেমন 60 দিলে প্রতি ঘণ্টায় নিজে থেকেই যাবে।

এই সাইটটি পাবলিক ও সার্চ-ইঞ্জিনের জন্য খোলা (robots.txt + sitemap.xml আছে)। তবু গুগল নিজে থেকে ঠিক সময়ে ইনডেক্স করে না — দ্রুত করতে Google Search Console-এ সাইটটি যোগ করে URL Inspection → Request Indexing চাপুন। নতুন সাইটে সাধারণত কয়েক দিন থেকে কয়েক সপ্তাহ লাগে। দ্রুত ও নিশ্চিত ফল পেতে takapai নামে নিজের ডোমেইন (যেমন takapai.com) নিয়ে সাইটটি সেখানে পয়েন্ট করাই সর্বোত্তম।

নিজের ক্লাউড ডাটাবেস (Postgres/MySQL) অ্যাড করা যাবে?

সার্ভারটি নিজের ডাটাবেস হিসেবে SQLite ব্যবহার করে — অর্থাৎ ডাটা আপনার নিজের মেশিনেই থাকে, কোনো ক্লাউড ডাটাবেস সার্ভিসের উপর নির্ভরতা নেই। ক্লাউডে ডাটা রাখতে চাইলে ব্যাকআপ ট্যাব থেকে নিজের R2/S3/B2/MinIO বাকেট যোগ করুন — ব্যাকআপ স্বয়ংক্রিয়ভাবে ক্লাউডে যাবে এবং যেকোনো সময় ফিরিয়ে আনা যাবে। সরাসরি Postgres/MySQL ড্রাইভার এখনো নেই; সেটি চাইলে জানান।

সাবডোমেইন নিজের পছন্দমতো (takapai.xxx) নিতে পারব?

Freebuff Sites-এ সাবডোমেইন স্বয়ংক্রিয়ভাবে তৈরি হয়। নিজের নাম চাইলে একটি ডোমেইন কিনে সেটি এই সাইটে পয়েন্ট করতে হবে — তখন takapai.example.com ঠিকানায় সাইট চলবে।

অ্যাপে বারবার “সংযোগ ব্যর্থ” আসছে কেন?

তিনটি কারণ সাধারণত: (১) সার্ভারের ঠিকানা ভুল বা শেষে / আছে, (২) ফোন ও সার্ভার একই নেটওয়ার্কে নেই, (৩) সার্ভার http:// আর ফোন https:// আশা করছে। ড্যাশবোর্ড ব্রাউজারে খুলে নিশ্চিত করুন ঠিকানা ঠিক আছে, তারপর হুবহু সেটাই অ্যাপে দিন।

পেমেন্ট হচ্ছে কিন্তু ম্যাচ হচ্ছে না

চারটি জিনিস মিলতে হয়: প্রোভাইডার, হুবহু টাকা, প্রেরকের নম্বর, আর অর্ডারটি pending থাকতে হবে। ড্যাশবোর্ড → লাইভ ফিডে দেখুন SMS এসেছে কি না, আর কোন কারণে বাদ পড়েছে (not_incoming_payment, amount_not_found ইত্যাদি)।

আমার নিজের ক্লাউড ডাটাবেস ব্যবহার করা যাবে?

বর্তমানে সার্ভারটি SQLite ফাইলে ডেটা রাখে (DATABASE_FILE এনভায়রনমেন্ট ভ্যারিয়েবল দিয়ে পাথ বদলানো যায় — মাউন্ট করা ক্লাউড ভলিউমও দেওয়া যায়)। Postgres/MySQL-এর মতো বাইরের ডাটাবেসে সরাসরি সাপোর্ট এখনো যোগ হয়নি — সেটি পরবর্তী ধাপ।

এই সাইটের সাথে ফোনের অ্যাপটা কীভাবে যুক্ত?

অ্যাপকে শুধু “আপনার সার্ভারের ঠিকানা” জানাতে হয়, তারপর পেয়ারিং কোড দিয়ে নিজের ইউনিক কী নেয়। এরপর প্রতিটি মেসেজ ওই সার্ভারেই যায়। কোনো মাঝখানের কোম্পানি নেই — সম্পূর্ণ আপনার নিয়ন্ত্রণে।

টাকাপাই — বিকাশ / রকেট / নগদ পেমেন্ট যাচাই।

অ্যাপটি শুধু আপনার নিজের ব্যবসার সিমে চলা ফোনে ব্যবহার করুন। অন্যের এসএমএস পড়া আইনত অপরাধ।
